01 / THE PROJECT’S CORE PRINCIPLE

Facts first.
Words second.

The repository separates deterministic extraction and range comparison from optional AI prose. The model does not decide whether a number is high or low.

01 / EXTRACTRead the report

Text PDFs use a text layer; scanned pages or images need OCR. Unreadable values are not silently “fixed.”

02 / VALIDATEUse its own range

Ordinary code compares values against the range printed on that report. Without a usable range, the status remains unknown.

03 / EXPLAINKeep AI optional

Optional prose explains verified facts. A contradicting model response can be rejected; the checked results remain the authority.
